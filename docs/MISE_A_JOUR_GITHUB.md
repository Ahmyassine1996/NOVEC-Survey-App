# Publier NOVEC Survey V1.8 sur le même dépôt

1. Sur chaque téléphone : télécharger les enquêtes (ZIP complet) et vérifier que le fichier existe, puis en garder une copie hors du téléphone.
2. Décompresser `NOVEC_Survey_V1.8.zip`. Copier **son contenu** directement à la racine du dépôt GitHub existant. Remplacer les fichiers de même nom, sans conserver d'anciens fichiers JS qui ne sont plus référencés.
3. `Commit & Push` sur `main`, attendre `github-pages` réussi ; garder la même URL.
4. Sur chaque appareil, ouvrir `mise-a-jour.html`, puis la PWA. Ne pas vider le stockage du site, ni supprimer l'application installée.
5. Vérifier les fiches anciennes, les identifiants conservés, les codes métier mis à jour, et les ZIP/Word. Prendre une photo avec le GPS réel et faire un essai hors connexion.

**Attention** : il y a une migration des *codes métier* à la première ouverture. Les codes antérieurs restent archivés ; les identifiants internes et les médias ne sont pas renumérotés. Avant publication, une sauvegarde complète de chaque appareil est nécessaire.

Documentation GitHub : https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
