NOVEC SURVEY V1.6 — MÊME APPLICATION, MÊME DÉPÔT

1. Sur CHAQUE appareil contenant des enquêtes V1.4 ou V1.5 : Paramètres → Sauvegarde JSON de secours (V1.5), ou Sauvegarde complète JSON (V1.4). Vérifier le téléchargement et conserver le fichier.
2. Extraire NOVEC_Survey_V1.6_CODE_COMPLET.zip sur le PC.
3. Ouvrir https://github.com/Ahmyassine1996/NOVEC-Survey-App sur la branche main.
4. Add file → Upload files. Ouvrir le dossier extrait et glisser TOUT SON CONTENU à la racine du dépôt, en conservant les sous-dossiers.
   index.html, sw.js et mise-a-jour.html doivent être directement visibles à la racine. Ne pas envoyer le dossier parent ni seulement le ZIP.
5. Commit changes. Conserver la configuration Pages existante. Attendre la coche verte du déploiement dans Actions.
6. Fermer les anciennes fenêtres NOVEC. Avec Internet, ouvrir :
   https://ahmyassine1996.github.io/NOVEC-Survey-App/mise-a-jour.html
   Cliquer « Installer la version 1.6 ».
7. Vérifier la version et les enquêtes existantes. Ne pas effacer les données du navigateur.
8. Sur un nouvel appareil, restaurer le JSON V1.4 ou un ZIP de données V1.6 via Exports, puis renseigner son profil et son code mission.

Adresse inchangée : https://ahmyassine1996.github.io/NOVEC-Survey-App/
Aucun nouveau dépôt à créer.

Le ZIP CODE_COMPLET sert à publier l’application. Les ZIP de données téléchargés depuis l’application servent à conserver/restaurer les enquêtes : ne jamais les déposer dans GitHub.

Avant la mission, faire un essai sur le téléphone : photo, GPS, ouvrage, photo d’ouvrage, mode avion, fermeture/réouverture, export et restauration.
