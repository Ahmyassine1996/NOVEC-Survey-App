Après publication en HTTPS :
1. Ouvrir l'URL sur le téléphone.
2. Autoriser la localisation précise dans Chrome.
3. Tester le bouton "Enregistrer le GPS" puis une photo.
4. Installer NOVEC Survey via le bouton affiché dans l'application ou via le menu Chrome.

- nom de l'application : NOVEC Survey ;
- logo NOVEC Groupe CDG intégré dans l'en-tête ;
- icônes d'installation Android/PWA générées à partir du logo fourni ;
- nom PWA harmonisé dans le manifest et l'interface.
