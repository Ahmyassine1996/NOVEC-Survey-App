NOVEC Survey v1.3

Publier sur GitHub Pages le contenu du ZIP (index.html et dossiers au niveau racine).
Avant toute mise à jour, exporter les fiches JSON des téléphones qui contiennent des relevés.

Nouveautés : design mobile, écran de saisie plus simple, photo GPS obligatoire et coordonnées EXIF réellement inscrites dans les nouveaux JPEG.

PAS de synchronisation centrale dans cette version. Les fichiers de terrain sont enregistrés uniquement dans le navigateur de l’appareil et les sauvegardes/exports effectués par l’utilisateur.
