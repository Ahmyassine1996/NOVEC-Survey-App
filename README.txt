NOVEC Survey V0.5 PWA HTTPS

Ce dossier est prêt à être publié sur un hébergement statique HTTPS (par exemple GitHub Pages).

Fichiers :
- index.html
- manifest.json
- sw.js
- icons/icon-192.png
- icons/icon-512.png

Après publication en HTTPS :
1. Ouvrir l'URL sur le téléphone.
2. Autoriser la localisation précise dans Chrome.
3. Tester le bouton "Enregistrer le GPS" puis une photo.
4. Installer NOVEC Survey via le bouton affiché dans l'application ou via le menu Chrome.

IMPORTANT :
- Utiliser cette publication gratuite uniquement comme prototype.
- GitHub Pages gratuit nécessite normalement un dépôt public ; ne mettez aucune donnée terrain réelle ou sensible dans le dépôt.
- Les données saisies par l'application restent pour l'instant stockées localement dans le navigateur du téléphone.
- La synchronisation OneDrive NOVEC viendra dans une étape ultérieure.
